## 二、不同规模模型的算力需求

### 2.1 计算公式

根据 Chinchilla 定律和实践经验：

**训练 FLOPs ≈ 6 × N × D**

其中：
- N = 模型参数量
- D = 训练 token 数
- 6 = 每个 token 的前向+反向传播 FLOPs 系数

**Chinchilla 最优 token 比例：D ≈ 20 × N**

但现代实践（LLaMA 系列等）倾向于过训练（overtrain），使用远超 20× 的 token 比例来在推理时获得更好的性价比。例如 LLaMA 3 8B 用了 15T tokens（≈1,875× 参数量）。

### 2.2 各规模模型估算

以下按 **Chinchilla 最优**和**现代过训练**两种模式估算：

#### 1B 参数模型

| 策略 | Token 数 | 总 FLOPs | H100 GPU 小时 | A100 GPU 小时 |
|------|----------|----------|---------------|---------------|
| Chinchilla (20×) | 20B | 1.2×10²⁰ | ~17 hrs | ~53 hrs |
| 过训练 (200×) | 200B | 1.2×10²¹ | ~170 hrs | ~530 hrs |
| 激进过训练 (1T tokens) | 1T | 6×10²¹ | ~850 hrs | ~2,700 hrs |

**VRAM 需求**：
- 全精度训练（BF16 + 优化器状态）：~16-20GB
- 单卡 RTX 4090 即可训练（24GB VRAM）
- 使用 ZeRO-1 优化可以更轻松

#### 7B 参数模型

| 策略 | Token 数 | 总 FLOPs | H100 GPU 小时 | A100 GPU 小时 |
|------|----------|----------|---------------|---------------|
| Chinchilla (20×) | 140B | 5.9×10²¹ | ~840 hrs | ~2,600 hrs |
| LLaMA 2 实际 | 2T | 8.4×10²² | ~12,000 hrs | ~37,000 hrs |
| LLaMA 3 实际 | 15T | 6.3×10²³ | ~90,000 hrs | ~280,000 hrs |

**参考实际数据**：Meta 报告 LLaMA 3 8B 使用了 **130 万 H100 GPU 小时**（含 15T token 训练 + 所有实验和失败的 run）。

**VRAM 需求**：
- 全精度训练：~70-100GB（需要至少 2×A100 80GB 或 1×H100 + ZeRO）
- 混合精度 + ZeRO-3：4×RTX 4090 可行但效率低
- 推荐配置：4-8×A100 或 4×H100

#### 13B 参数模型

| 策略 | Token 数 | 总 FLOPs | H100 GPU 小时 | A100 GPU 小时 |
|------|----------|----------|---------------|---------------|
| Chinchilla (20×) | 260B | 2.0×10²² | ~2,800 hrs | ~8,900 hrs |
| 实际训练 (~2T) | 2T | 1.6×10²³ | ~22,000 hrs | ~70,000 hrs |
| 激进训练 (~5T) | 5T | 3.9×10²³ | ~56,000 hrs | ~174,000 hrs |

**VRAM 需求**：
- 全精度训练：~130-200GB
- 推荐配置：8×A100 或 4-8×H100
- RTX 4090 勉强可行需大量优化（QLoRA 微调可以，预训练不实际）

#### 70B 参数模型

| 策略 | Token 数 | 总 FLOPs | H100 GPU 小时 | A100 GPU 小时 |
|------|----------|----------|---------------|---------------|
| Chinchilla (20×) | 1.4T | 5.9×10²³ | ~84,000 hrs | ~260,000 hrs |
| LLaMA 2 实际 | 2T | 8.4×10²³ | ~120,000 hrs | ~370,000 hrs |
| LLaMA 3 实际 | 15T | 6.3×10²⁴ | ~900,000 hrs | ~2,800,000 hrs |

**参考实际数据**：Meta 报告 LLaMA 3.1 70B 使用了 **700 万 H100 GPU 小时**。

**VRAM 需求**：
- 全精度训练：~700-1000GB
- 最低配置：16×A100 80GB（使用 ZeRO-3 + 梯度检查点）
- 推荐配置：64-128×H100（使用 3D 并行）
- RTX 4090 完全不可行用于预训练

## 三、详细成本估算

### 3.1 云端租赁成本（按 2026 年初价格）

以 H100 云端 $2.99/hr（经济型提供商如 Jarvislabs/RunPod/Lambda）计算：

| 模型规模 | GPU 数 × 类型 | GPU 小时 | 挂钟时间 | 云端成本 |
|----------|--------------|----------|----------|----------|
| **1B（Chinchilla）** | 1× H100 | 170 hrs | ~1 周 | **~$500** |
| **1B（1T tokens）** | 4× H100 | 3,400 hrs | ~5 周 | **~$10,000** |
| **7B（Chinchilla）** | 8× H100 | 6,700 hrs | ~5 周 | **~$20,000** |
| **7B（2T tokens）** | 8× H100 | 96,000 hrs | ~1.5 月 | **~$287,000** |
| **13B（Chinchilla）** | 8× H100 | 22,400 hrs | ~4 月 | **~$67,000** |
| **13B（2T tokens）** | 16× H100 | 176,000 hrs | ~16 月 | **~$526,000** |
| **70B（Chinchilla）** | 64× H100 | 5.4M hrs | ~3.5 月 | **~$16M** |
| **70B（LLaMA 3 级）** | 256× H100 | 900K+ hrs | ~5 月 | **~$100M+** |

> 注：实际成本会因硬件利用率（MFU，通常 40-55%）、通信开销、失败重启等增加 50-100%。

### 3.2 自建集群成本

#### 小型集群（8× H100 SXM DGX）

| 项目 | 成本 |
|------|------|
| DGX H100 系统（8 GPU） | ~$300,000-400,000 |
| InfiniBand 交换机 + 网络 | ~$30,000-50,000 |
| 电力基础设施 | ~$15,000-30,000 |
| 冷却系统 | ~$15,000-50,000 |
| 机架 + 其他 | ~$10,000-20,000 |
| **总计** | **~$370,000-550,000** |
| **月电费**（5.6kW × 24h × 30d × $0.10/kWh） | ~$4,000/月 |

**云端盈亏平衡点**：假设月云费 $17,000（8×H100×$2.99×24h×30d），自建约 22-32 个月回本。

#### 预算型集群（8× RTX 4090）

| 项目 | 成本 |
|------|------|
| 8× RTX 4090 GPU | ~$12,800 |
| 2× 主机（CPU/内存/主板/电源） | ~$6,000-10,000 |
| 网络（10GbE/25GbE） | ~$1,000-3,000 |
| **总计** | **~$20,000-26,000** |
| **月电费**（3.6kW × 24h × 30d × $0.10/kWh） | ~$2,600/月 |

**但要注意 4090 的严重限制**：
- ❌ 不支持 NVLink（多卡通信只能走 PCIe，带宽 64GB/s vs H100 NVLink 900GB/s）
- ❌ 只有 24GB VRAM（7B 全精度训练已经吃紧）
- ❌ NVIDIA 许可协议禁止在数据中心使用消费级 GPU（法律风险）
- ❌ 多卡并行训练效率远低于 A100/H100 集群
- ✅ 单卡性价比极高（FP16 330 TFLOPS / $1,600）
- ✅ 适合 1B 模型训练和 ≤13B 模型的 QLoRA 微调

### 3.3 TPU 训练成本

> TPU 的价格优势主要体现在长期承诺和大规模场景。但需要 JAX/TensorFlow 开发栈。

## 四、硬件选型建议

### 4.1 按模型规模推荐

| 目标模型 | 推荐方案 | 预算范围 | 备注 |
|----------|---------|----------|------|
| **≤1B 参数** | 1-2× RTX 4090 自建 | $3,000-5,000 | 最高性价比，个人可负担 |
| **1-3B 参数** | 4× RTX 4090 或 2× A100 云端 | $5,000-30,000 | 4090 集群可行但效率不如 A100 |
| **7B 参数** | 8× A100/H100 云端 | $20,000-300,000 | 取决于 token 数量，云端按需最灵活 |
| **13B 参数** | 8-16× H100 云端或自建 | $70,000-500,000 | 建议混合策略 |
| **70B 参数** | 64-256× H100 或 TPU Pod | $10M-100M+ | 仅顶级实验室和企业可负担 |

### 4.2 按预算推荐

| 预算 | 可训练最大模型 | 推荐方案 |
|------|--------------|----------|
| **$1,000 以下** | 1B（Chinchilla 最优） | 云端 A100 按小时租 |
| **$1,000-5,000** | 1-3B | 1-2× RTX 4090 自建 或 云端 H100 |
| **$5,000-50,000** | 3-7B | 云端 8× H100 短期训练 |
| **$50,000-500,000** | 7-13B | 自建 8× H100 DGX 或长期云租 |
| **$500K-10M** | 13-70B | 大规模云集群或 TPU Pod |
| **$10M+** | 70B+ | 企业级 GPU/TPU 超级集群 |

### 4.3 个人/小团队的实际路线图

如果目标是**学习和实验**（预算 $5,000-20,000）：

1. **起步**：1× RTX 4090（$1,600），训练 <1B 模型理解全流程
2. **进阶**：扩展到 2-4× RTX 4090（$5,000-7,000），训练 1-3B 模型
3. **扩大**：租用云端 8× H100（$3/hr/GPU），短期突击训练 7B 模型
4. **优化**：用 QLoRA/LoRA 微调开源 7B-13B 模型，在 4090 上即可完成

## 五、GPU vs TPU 深度对比

### 5.1 训练性能对比

| 维度 | NVIDIA GPU (H100) | Google TPU (v6e) | 胜出 |
|------|-------------------|------------------|------|
| **单芯算力 (BF16)** | 1,979 TFLOPS | ~400 TFLOPS | GPU |
| **集群扩展性** | NVLink + InfiniBand | ICI 自研互联 | TPU（更简单） |
| **软件生态** | CUDA/PyTorch | JAX/TensorFlow | GPU（更广泛） |
| **性价比（按需）** | ~$2.99/hr | ~$1.375/hr | TPU |
| **性价比（承诺）** | ~$1.90/hr | ~$0.55/hr | TPU |
| **可用性** | 广泛 | 仅 Google Cloud | GPU |
| **灵活性** | 任何框架 | 主要 JAX/TF | GPU |
| **大规模训练效率** | 优秀 | 优秀（Pod 架构） | 持平 |

### 5.2 选择建议

**选 GPU（H100/A100）当：**
- 使用 PyTorch（99% 的研究者默认选择）
- 需要灵活切换不同云提供商
- 团队已有 CUDA 开发经验
- 需要在训练和推理之间灵活分配资源
- 中小规模（≤128 GPU）训练

**选 TPU 当：**
- 使用 JAX 或 TensorFlow
- 大规模训练（256+ 芯片 Pod）
- 注重长期成本（3 年承诺价格极低）
- Google Cloud 生态已是主要基础设施
- Transformer 类模型为主要工作负载

**选 RTX 4090 当：**
- 个人学习和实验
- 预训练 ≤3B 参数模型
- 微调 ≤20B 参数模型（QLoRA）
- 预算极其有限
- 不需要多卡并行（单卡完成）

### 6.2 关键洞察

1. **DeepSeek V3 的启示**：671B MoE 模型仅花 $5.6M 和 2.7M H800 GPU 小时，证明了高效训练工程的巨大价值。优秀的工程能力可以将成本降低 10-50 倍。

2. **过训练趋势**：现代模型远超 Chinchilla 最优比例，用更多数据训练较小模型，在推理成本上获得优势。LLaMA 3 8B 的 15T tokens 是 Chinchilla 最优的 ~94×。

3. **MFU 的重要性**：模型 FLOPS 利用率（MFU）通常只有 40-55%，意味着实际需要的 GPU 小时是理论值的 2-2.5 倍。提高 MFU 是降低成本最直接的方式。

## 七、总结与建议

### 对于学习/研究目的
- **最佳入门方案**：1× RTX 4090 + 1B 参数模型 + Chinchilla 最优 tokens。总成本 <$2,000，可在 1 天内完成训练。
- **进阶方案**：云端 8× A100/H100 按需租用，训练 7B 模型。控制 token 数在 500B 以内，成本 $5,000-10,000。

### 对于创业/商业目的
- **7B 模型**：准备 $50K-300K 预算，使用云端 H100 集群。
- **13B+ 模型**：准备 $100K+ 预算，考虑混合策略（TPU 长期承诺 + GPU 弹性计算）。
- **70B 模型**：不推荐从零训练，建议在开源模型基础上微调。

### 成本优化策略
1. 使用 Spot/Preemptible 实例（节省 60-70%）+ 良好的 checkpoint 机制
2. 混合精度训练（BF16/FP8）减少 VRAM 和计算需求
3. 高效的数据管道避免 GPU 空闲
4. MoE 架构降低同等质量下的算力需求
5. 渐进式训练：先小模型验证方案，再扩大规模
