## 📝 教训与改进

- 🔴 **铁律：绝不修改本地 API Proxy 代码** — 包括"临时 debug log"。唯一流程：GitHub branch → PR → CI → merge → `git pull` → `systemctl restart`
- 🔴 **修复事故时先恢复干净状态** — `git stash && git checkout .` 恢复到已知好的状态，然后再分析问题。不要在脏状态上叠加修复
- 🟡 **inotifywait 监听单文件 ≠ 监听文件变更** — 原子写入（unlink+create）不触发 modify 事件，必须监听目录
- 🟡 **事件驱动系统的 handler 必须异步** — 同步处理会阻塞主循环，导致后续事件漏检
- 🟡 **shell 脚本参数必须有 fallback** — 位置参数在不同调用方式下含义不同，要做智能识别
- 🟡 **urllib.request.urlopen 没有默认 timeout** — 网络不稳定时无限挂住，必须显式设置
- 🟡 **多入口写同一种数据时，必须共用映射逻辑** — init 和 replan 各写各的导致 key 映射不一致
- 🟡 **固化 = 代码，不是 prompt** — 任何需要"记住去做"的事情，都应该写进代码/脚本/配置，而不是靠 LLM 记忆
