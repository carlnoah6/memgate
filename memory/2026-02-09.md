### 21:00 — Lark 卡片按钮回调功能上线 ✅

**功能**：发送带按钮的交互式卡片，用户点击后 Luna 收到回调
**用途**：操作确认（重启/部署）、选择题、审批流

**架构**：
1. 发送 `msg_type: interactive` 卡片（v1 schema，含 `action` 元素 + `button` 组件）
2. 用户点击 → Lark 发 `card.action.trigger` 事件到「回调配置」URL
3. api-proxy (`/api/oauth/callback`) 检测到 card.action.trigger → 转发到 OpenClaw webhook (`/webhook/lark`)
4. Feishu 插件 (`channel.ts`) 将按钮点击转换为合成 `im.message.receive_v1` 消息
5. Luna 收到: `[按钮] <value>`

**关键发现**：
- Lark 卡片按钮回调和 OAuth 回调共用一个 URL 配置（「回调配置」）
- 「回调配置」指向 `/api/oauth/callback`（api-proxy 端口 8180），不是事件 webhook
- 「事件配置」指向 `/webhook/lark`（OpenClaw 端口 18789）
- 解决方案：在 api-proxy 的 POST handler 中检测 card.action.trigger → 转发到 webhook
- 卡片用 v1 schema（无 `"schema": "2.0"`），v2 不支持 `action` tag

**文件修改**：
- `/home/ubuntu/api-proxy/server.py` — POST `/oauth/callback` 增加 card action 转发
- `/home/ubuntu/.openclaw/plugins/feishu-webhook/src/channel.ts` — 拦截 card.action.trigger，生成合成消息
- `scripts/send-confirm-card.sh` — 发送确认卡片的工具脚本

**脚本用法**：
