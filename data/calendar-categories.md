## 设计理念（颜色心理学）
- **蓝** = 专注、专业 → 工作
- **橙** = 行动力、互动 → 会议
- **青绿** = 冷静、求知 → 学习
- **靛蓝** = 内省、深度 → 心理
- **粉** = 温暖、童趣 → 家庭
- **黄** = 阳光、友好 → 社交
- **绿** = 活力、健康 → 运动
- **紫** = 创意、享乐 → 休闲
- **灰** = 中性、日常 → 生活
- **红** = 紧急、注意 → 重要

## 使用方式

### 用户说"我在做 XX"
1. 创建一个日程，开始时间 = 当前时间
2. 默认时长 1 小时（可调）
3. 根据内容自动匹配分类和颜色
4. 如果用户说了持续时间，按用户说的来
5. **不加提醒**（Carl 不需要日程提醒）

### 排程规则
- Carl 早上 7:00 起床
- 小朋友晚饭一般 17:30-18:30
- 小朋友 20:00 左右上床睡觉
- **晚上不安排太晚的活动**，有孩子参与的日程尽量 20:00 前结束

### 分类优先级（多标签时）
1. 带孩子去的活动 → 👶 家庭（即使是音乐会/演出，带元宝朵朵的归家庭）
2. 纯自己享乐的演出/音乐会 → 🎮 休闲
3. 和朋友吃饭但也谈业务 → 📅 会议（业务优先）
4. 和朋友纯吃饭 → 🍻 社交
